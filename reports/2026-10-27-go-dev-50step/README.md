## 关键事实

1. **评分器会给 1.0**：v6 memory_harness 与 v8 baseline 的外卖子任务都拿到 1.0。订单是精确目标商品 `P00083 清汤面`，地址 `海昌路68号`，`shipping_time=25.0`（含 25 分钟），非方便面，已支付。这证明此前“评分器坏了”不是问题。
2. **baseline 也能拿 0.5**：v8 的 baseline 没有任何 guards/memory，同样满足外卖 rubric。因此 v6 的 0.5 不能归因于 memory_harness。
3. **酒店子任务三组全 0**：
   - 速8/城市便捷等酒店即使标签含“浴缸”，具体房型也可能不带浴缸；v6 前把酒店标签传播到所有房间，guard 误判通过。
   - v7 修正后，agent 在用户坚持要 2/11 非浴缸房时选择拒单并让用户“自行修改偏好”，没有回到已搜索到的目标酒店 `都市118连锁酒店(重庆大学城店)`（H00043）。
   - v8 增加系统提示候选列表，但该组 memory_harness 的酒店阶段根本没有成单。
4. **v8 暴露出候选提示的误报**：旧提示把配送时间未知的“酸辣粉”写成“符合所有硬性约束”，agent 据此下单，实际 `shipping_time=26.0`，超过 25 分钟。已修复：候选只有在每个硬约束都有可观察证据时才列出；未知一律不声称满足。修复后单测覆盖（`test_delivery_hint_never_claims_unknown_delivery_time_is_satisfied`）。
5. 所有运行工具错误 0；终止原因均为 `agent_stop`/`user_stop`，没有 `max_steps`。
